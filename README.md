# **Sales Analysis in Power BI and SQL**

## This project uses Power BI Desktop and MS SQL Server to help to extract and visualize insights for analyzing the potential of customers, countries, and products.

## **Key Features:**
📌 Sale Analyst: extract and visualize insights for analyzing the potential of customers, countries, and products.

📌 Customer Segmentation: Group customers based on shared characteristics and churn risk, allowing for targeted marketing and engagement efforts.
